# ProyectoAquaChile
Plataforma web desarrollada para la automatización y gestión integral de procesos de reclutamiento. El sistema está dividido en dos módulos principales: un portal público para la recepción de postulaciones y carga de currículums, y un panel de administración interno interactivo (tablero Kanban) para que el equipo de psicólogos gestione el avance de las evaluaciones.

Tecnologías Utilizadas
Frontend (Interfaz de Usuario)
  React: Biblioteca principal para la construcción de componentes modulares y reactivos.

  Vite: Herramienta de empaquetado ultra rápida para el entorno de desarrollo.

  CSS3 Avanzado: Implementación de interfaces responsivas y diseño moderno en Dark Mode sin depender de librerías externas pesadas.

  HTML5 Drag & Drop API: Manejo de interacciones nativas para el movimiento de tarjetas de candidatos.

Backend (Lógica y API)
  Java + Spring Boot: Framework robusto para la construcción del monolito y la exposición de endpoints RESTful.

  Spring Data JPA & Hibernate: ORM utilizado para el mapeo objeto-relacional y la interacción fluida con la base de datos.

  Lombok: Herramienta para la reducción de código repetitivo (getters, setters, constructores).

  Spring Security & JWT: Gestión de autenticación, protección de rutas y validación de roles de usuario (Analista, Evaluador, Administrador).

Base de Datos & Almacenamiento
  SQL Relacional: Base de datos centralizada para garantizar la integridad de los registros de candidatos, cargos, evaluaciones y usuarios del sistema.
